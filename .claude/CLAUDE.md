# WHY

anyhost keeps every Claude Code and Codex session of every machine the Architect works on in Cloudflare R2, lists every session on every machine, and resumes a Claude Code session on any machine, so a dead or busy machine never holds his history hostage.

# Facts

- The repository root is a cmod mod: `src/mod.ts` is the `defineMod`, `hooks/register.ts` only registers it, and `tests/` holds its `bun test` suite. `node_modules/@cmodjs/core/docs/` is the cmod documentation for the installed version.
- `cli/` is the `anyhost` program, TypeScript on Bun with its own `package.json`, `bun.lock` and `tsconfig.json`. `bun run --cwd cli build` compiles `cli/dist/anyhost-<os>-<arch>` with `bun build --compile` for each machine in `CMOD_MACHINES`, or all four, as cmod builds its own program, and runs `bun install` first. `bun run --cwd cli check` type-checks it. `bun test` at the root runs the mod's tests and `cli/tests/`, while `cmod check .` runs only the mod's.
- `package.json` `cmod.program` names `anyhost`, and `cli/package.json` names `bun run build` as its build, so `cmod publish` attaches `anyhost-<os>-<arch>` for darwin and linux on arm64 and x64 to each GitHub release, `cmod install` downloads it, and `cmod link` builds it from the checkout.
- The program reads its version from `.claude-plugin/plugin.json` at build time, so a release raises only that file's `version`.
- A push to `main` runs `.github/workflows/ci.yml`, which tests and, when the tag `v<version>` is missing, runs `cmod publish`. `docs/releasing.md` holds the steps.
- The program is the only code that talks to R2, through `@aws-sdk/client-s3` with the AWS profile `r2` as client options, never as `AWS_PROFILE`, so `claude --resume` and everything else anyhost runs keeps the shell's AWS profile. The client's `profile` option gives the keys and the region but not `endpoint_url`, so `cli/src/store.ts` reads the endpoint with `@smithy/core/config`'s `loadSharedConfigFiles`. The bucket is `anyhost`, or `ANYHOST_BUCKET`. Tests and test machines use `anyhost-test`, never `anyhost`.
- R2 answers a failed `If-None-Match` or `If-Match` with 412, which `Store.put` turns into `undefined`.
- The mod starts `anyhost serve` as a `singleInstance` program job with `device.read()` in `ANYHOST_DEVICE_*`. Every other command reads the machine from `cmod device --json`, through `~/.local/share/cmod/programs/cmod`, else the `cmod` on `PATH`, so it works over `ssh` with no session open.
- `anyhost serve` rewrites `devices/<id>.json` at start and every 5 minutes, so the record's R2 modified time says the named machine still runs. A start under another name than the record's is a rename once that time is 10 minutes old, and a clone before that. A clone exits before the program prints its address, so cmod shows its last standard error line in the `The anyhost program stopped` toast after 5 tries. A renamed machine started within those 10 minutes shows the same toast, which names the time its Retry works. A network failure at start only delays the registration, and capture waits for it.
- At start, every file whose size passed its offset enters the backlog. Each 30-second pass uploads the files the watcher named first, 4 at a time, writes `index.json` when it changed, then works the backlog 2 at a time until 20 seconds into the pass, so a live session reaches the list within one pass while the backlog runs, and the backlog's index entries go out with the next pass.
- Codex keeps a thread's name in `~/.codex/session_index.jsonl`, not in its transcript, so a Codex session's title comes from that file.
- Claude Code writes `~/.claude/projects/<working folder with every character but letters and digits as ->/<session>.jsonl`, and a subagent's transcript under `<session>/subagents/`. A transcript's R2 key is its path under the project folder without `.jsonl`, so a subagent's segments live under its session's folder. Codex keys a session by the uuid at the end of its `rollout-*.jsonl` name.
- Claude Code only appends to a transcript. A transcript that shrinks is left at the bytes uploaded, with an error.
- The program keeps each file's offset and each session's index entry in `~/.local/state/anyhost/anyhost.db`, which `anyhost resume` writes too. A resumed transcript's row maps local bytes from `local_start` to the transcript's bytes from `remote_start`, because the resume rewrote its `cwd` fields and changed its length.
- A device uploads no more of a session another device claims. `chainOf` follows the longest chain of segments from byte 0, so the lines an old holder wrote before it saw the claim never enter the transcript.
- `fs.watch` with `recursive` hears new folders on macOS and on Linux, and the program polls no file: a file enters the next 30-second pass only when the watcher names it, or at start when its size passed its offset.
- OrbStack machines don't resolve Tailscale names, so a test machine reaches the pool at `http://devbox:8317` through an `/etc/hosts` line for devbox's Tailscale address.
